## What it is

SnuggleFox writes a short bedtime story from what a parent types in: the child's name, age, and favourite things, and optionally something that happened that day. The parent owns the account and every input.

I built it for bedtime at home, and it isn't a children's brand.

## How it works

- A parent describes the child
- They can add a detail from today
- The story ends calmly, so it works at bedtime

The stories are generated text, so a parent should read each one before sharing it with a child.
